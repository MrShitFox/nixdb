# Single-host example

This is a non-production example using deliberately fake paths, project IDs,
and `CHANGE_ME` credentials. Replace the filesystem declaration with the real
host configuration generated by `nixos-generate-config`, choose unique project
IDs and ports, and replace every example credential before deployment.

Listeners default to loopback and firewall ports remain closed. Set
`bindAddress` and `openFirewall` explicitly only when remote access is intended.
