# Security policy

## Supported versions

Security fixes are provided for the latest tagged release. Older releases may
receive fixes when a safe backport is practical.

## Reporting a vulnerability

Do not open a public issue containing credentials, exploit details, private
host configuration, or an unpatched vulnerability. Use GitHub private
vulnerability reporting for this repository. Include affected versions,
impact, reproduction details, and a proposed mitigation when available.

For ordinary non-sensitive bugs, use the public issue tracker.
